# CommonBeacon

A customer-support community built with Java, Spring Boot, PostgreSQL, and React.

## Project status

Planning is complete. Application implementation has not started.

The first milestone delivers local accounts, public boards, questions, replies, accepted solutions, server-enforced permissions, automated tests, and Docker Compose startup.

## Planned stack

- Java 21 and Spring Boot with Maven.
- PostgreSQL with Flyway migrations.
- React and TypeScript with Vite.
- Docker Compose for local execution.
- REST initially; GraphQL after the core workflow is verified.

Exact dependency versions and runnable setup commands will be documented during implementation.

## Identity

CommonBeacon is an independent learning and portfolio project using original branding. The Java base package is `com.lawrencenno.commonbeacon`.
